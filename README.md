# jrm-code-public
Public copy of jrm-code-project minus the secret stuff.

Because the secret stuff is not included, this repository is not
functional on its own. It is intended to be used as a reference for
the public parts of the jrm-code-project. 

Feel free to extract the code and use it in your own projects, but
please be aware that it may not work without the secret parts of the
original project.
